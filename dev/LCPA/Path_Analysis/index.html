Path Analysis and Routing

This section contains the core algorithmic implementations to compute the shortest paths across the weighted adjacency matrices, including Dijkstra's algorithm and large-scale parallelized distance computations.

Shortest Path Algorithms

ArcheoGra.LCPA.neighbours — Function
neighbours(u::Int, Ad::SparseMatrixCSC{<:Number})

Retrieves the neighbouring nodes for a given node u.

Neighbours are defined as all cells with strictly positive values in the u-th column of the adjacency matrix.

Arguments

  • u::Int: The node index.
  • Ad::AbstractArray{<:Number}: The adjacency matrix of the graph.

Output

  • Vector{Int}: A vector containing the indices of all adjacent nodes.
ArcheoGra.LCPA.delConnections — Function
delConnections(Ad::AbstractMatrix, keepNodes::AbstractVector{Bool})

Removes unwanted connections from an adjacency matrix based on a boolean mask.

Arguments

  • Ad::AbstractMatrix: The original adjacency matrix representing the graph.
  • keepNodes::AbstractVector{Bool}: A boolean vector where true indicates a node (and its connections) should be kept.

Output

  • SparseMatrixCSC: A new adjacency matrix with the specified nodes entirely isolated/removed.
ArcheoGra.LCPA.compress — Function
compress(Topdata::AbstractLCPAData, k::Int, l::Int)

Compresses a cost raster matrix by averaging blocks of k × l cells into single cells.

Arguments

  • Topdata::AbstractLCPAData: Topographical data structure containing the CostMap to be compressed.
  • k::Int: Number of rows to aggregate per block.
  • l::Int: Number of columns to aggregate per block.

Output

  • TopographicalData: A new data structure containing the compressed matrix.
ArcheoGra.LCPA.get_path — Function
get_path(u::Int, start::Int, predecessor::AbstractVector)

Reconstructs the shortest path from the start node to the target node.

Arguments

  • u::Int: The target node index.
  • start::Int: The source node index.
  • predecessor::AbstractVector: The predecessor array generated by the shortest path algorithm.

Output

  • Vector{Int}: An ordered list of node indices representing the path from the target back to the start.
ArcheoGra.LCPA.dijkstra_shortest_path — Function
dijkstra_shortest_path(Ad::SparseMatrixCSC{<:Number}, start::Int; targets::Vector{Int}=Int[])

Calculates the shortest paths from a start node using an optimized Min-Heap Dijkstra algorithm.

Arguments

  • Ad::SparseMatrixCSC{<:Number}: Weighted adjacency matrix representing the graph.
  • start::Int: Source node index.

Keywords

  • targets::Vector{Int}: Optional list of target nodes. If provided, the algorithm stops early once all targets are reached.

Output

  • Tuple{Vector{Float64}, Vector{Int}}: A tuple containing the travel costs to each node (-1.0 if unreachable) and the predecessor list.

Multi-Pair LCPA Pipelines

ArcheoGra.LCPA.all_pairs_LCPA — Function
all_pairs_LCPA(TopData::TopographicalData, Ad::AbstractMatrix, sites::AbstractVector)

Calculates the least cost paths between all provided coordinate sites and plots the results.

Arguments

  • TopData::TopographicalData: Topographical data structure.
  • Ad::AbstractMatrix: The adjacency matrix representing the graph.
  • sites::AbstractVector: A list of target site coordinates (latitude, longitude).

Output

  • nothing: The function generates and displays a Plots.jl visualization.
ArcheoGra.LCPA.all_pairs_LCPA_GMT — Function
all_pairs_LCPA_GMT(TopData::TopographicalData, Ad::AbstractMatrix, sites::AbstractVector{Tuple{Real, Real}}; output_dir::String = pwd())

Calculates the least cost paths between all provided sites and plots the results using GMT.jl.

Arguments

  • TopData::TopographicalData: Topographical data structure.
  • Ad::AbstractMatrix: The adjacency matrix representing the graph.
  • sites::AbstractVector{Tuple{Real, Real}}: A list of site coordinates.

Keywords

  • output_dir::String: Directory to save the resulting map image (default: current working directory).

Output

  • nothing: Generates a high-quality GMT plot and saves it to disk.
ArcheoGra.LCPA.all_pairs_LCPA_adaptive — Function
all_pairs_LCPA_adaptive(TopData::TopographicalData, Ad_leaves::AbstractMatrix, leaves::Vector{Tuple{Int,Int,Int}}, L_geom::Int, sites::AbstractVector)

Performs a least cost path analysis between multiple sites on an adaptively refined quadtree graph.

Arguments

  • TopData::TopographicalData: Topographical data structure.
  • Ad_leaves::AbstractMatrix: The adaptive adjacency matrix.
  • leaves::Vector{Tuple{Int,Int,Int}}: Vector of adaptive quadtree leaf cells.
  • L_geom::Int: The finest geometric level of the quadtree decomposition.
  • sites::AbstractVector: A list of geographic coordinates.

Output

  • nothing: Generates and displays a Plots.jl visualization.
ArcheoGra.LCPA.all_pairs_LCPA_adaptive_GMT — Function
all_pairs_LCPA_adaptive_GMT(TopData::TopographicalData, Ad_leaves::AbstractMatrix, leaves::Vector{Tuple{Int,Int,Int}}, L_geom::Int, sites::AbstractVector{Tuple{Real, Real}}, r; output_dir::String = pwd())

Calculates the least cost paths on an adaptive graph and visualizes the results on a GMT map.

Arguments

  • TopData::TopographicalData: Topographical data structure.
  • Ad_leaves::AbstractMatrix: The adaptive adjacency matrix.
  • leaves::Vector{Tuple{Int,Int,Int}}: Vector of adaptive quadtree leaf cells.
  • L_geom::Int: The finest geometric level of the quadtree decomposition.
  • sites::AbstractVector{Tuple{Real, Real}}: Target site coordinates.
  • r::Float64: Compression or thresholding ratio parameter (used for file naming).

Keywords

  • output_dir::String: Directory to save the output map (default: current working directory).

Output

  • nothing: Generates and saves a GMT map.
ArcheoGra.LCPA.extract_quadratic_map — Function
extract_quadratic_map(TopoData::TopographicalData, N_1orN_2_offset::Int)

Extracts a square subsection of the cost map with a side length compatible with wavelet operations.

The dimensions are scaled to 2^n + offset, where n is the largest power of two fitting within the original map boundaries.

Arguments

  • TopoData::TopographicalData: Input topographical data structure.
  • N_1orN_2_offset::Int: Dimension offset mandated by the chosen wavelet boundary condition.

Output

  • Tuple{TopographicalData, Int}: A tuple containing the cropped quadratic map and the base exponent n.
