Network Generation and Connectivity

These functions handle the core logic of translating archaeological sites into a connected graph. This includes applying distance measures (like Haversine), calculating connection probabilities via Rayleigh functions, and ensuring the final stochastic graph forms a single connected component.

Distance and Basic Connectivity

Output

  • Float64: The distance in kilometers.

ArcheoGra.ConNetw.adjacency_data — Method
adjacency_data(Material_data::MaterialDataList, data::Arch_DataSet, time_period::String)

Reads in the shared raw material distribution of vertices for a given time period. Connectivity is stored in a weighted adjacency matrix, where the weight corresponds to the cumulative amount of shared material presence.

Arguments

  • Material_data::MaterialDataList: List of all materials and their corresponding properties.
  • data::Arch_DataSet: List of archaeological sites with their properties.
  • time_period::String: Time period in which the material connectivity is compared.

Output

  • Dict{String, Tuple{SparseMatrixCSC{Float64, Int}, Float64}}: A dictionary mapping the material name to a tuple of its weighted adjacency matrix and its distribution distance.

Output

ArcheoGra.ConNetw.RayleighSISO — Function
RayleighSISO(r::Number, r0::Number; beta::Number = 10.0, eta::Number = 2.0)

Evaluates the connectedness probability using a Rayleigh (SISO) mathematical model: $R(x)=e^{-\beta(\frac{r}{r_0})^{\eta}}$

Arguments

  • r::Number: The current measured distance.
  • r0::Number: The normalization or baseline maximum distance limit.

Keywords

  • beta::Number: The decay scaling parameter. Defaults to 10.0.
  • eta::Number: The exponent modifying distance penalization. Defaults to 2.0.

Output

  • Float64: The computed connection probability between 0.0 and 1.0.
ArcheoGra.ConNetw.connect_nodes — Method
connect_nodes(start_node::Int, end_node::Int, distance_matrix::AbstractArray{Float64}, material_weight_matrices::Dict, relevant_sites::Vector{ArchDataEntry}; symmetric::Bool = true)

Evaluates whether two nodes should be connected based on their geographic distance, group classification, and shared materials. Generates stacked probabilities by utilizing the RayleighSISO function, increasing the likelihood of connection for each shared material.

Arguments

  • start_node::Int: Index of the primary site.
  • end_node::Int: Index of the secondary site.
  • distance_matrix::AbstractArray{Float64}: Matrix containing distances between all nodes.
  • material_weight_matrices::Dict: Dictionary containing matrices for each material tracking the amount of shared items.
  • relevant_sites::Vector{ArchDataEntry}: Evaluated sites to access entry properties like group classifications.

Keywords

  • symmetric::Bool: Set to true to use symmetrical distances, or false to evaluate directional asymmetry. Defaults to true.

Output

  • Tuple: Returns boolean flags representing the material-enhanced connection and the default spatial connection. Returns 4 booleans if asymmetric, 2 if symmetric.
ArcheoGra.ConNetw.connect_nodes — Function
connect_nodes(start_node::Int, end_node::Int, distance_matrix::AbstractArray{Float64}, symmetric::Bool = true; distance_matrix_back::AbstractArray{Float64} = distance_matrix)

Variant of connect_nodes strictly designed to evaluate connections across time periods based exclusively on geographic limits without integrating material modifiers.

Arguments

  • end_node::Int: Index of the secondary site.
  • distance_matrix::AbstractArray{Float64}: Matrix containing spatial distances.
  • symmetric::Bool: Set to true to use symmetrical distances. Defaults to true.

Keywords

  • distance_matrix_back::AbstractArray{Float64}: Required if symmetric is false to determine reverse distances. Defaults to distance_matrix.

Output

  • Tuple: Returns boolean flags identifying whether nodes satisfy the spatial probability threshold.

Haversine Specific Networks

  • output_dir::String: Base directory to save CSV and map exports. Defaults to current working directory.
  • overwrite::Bool: Enables file overwrite privileges. Throws an error if set to false and the directory already exists.

Output

  • Vector{Any}: A collection of graph states and matrices mapped per time period.

ArcheoGra.ConNetw.Haversine_is_connected — Function
Haversine_is_connected(start_node::Int, end_node::Int, distance_matrix::AbstractArray{Float64}, material_weight_matrices::Dict; relevant_sites::Vector{ArchDataEntry})

Determines if two vertices should be connected based on spatial distance and shared material presence. The probability function relies on a Rayleigh model, where distance acts as a baseline, and shared materials increase connectivity likelihood. Group classifications can further increase connection probability.

  • end_node::Int: Index of the second vertex.
  • distance_matrix::AbstractArray{Float64}: Matrix containing distances between all vertices.
  • material_weight_matrices::Dict: Dictionary of material matrices and their corresponding distribution ranges.

Keywords

  • relevant_sites::Vector{ArchDataEntry}: List of all relevant archaeological sites to evaluate group classifications.

Output

  • Tuple{Bool, Bool}: Returns two booleans: (material_connection, default_connection).

Connected Components Assurance

ArcheoGra.ConNetw.components — Function
components(adj_mat::AbstractArray{<:Number})

Function to determine all components of given graph. Function is an adjusted version of the function "connect_components" from the Graphs.jl package. Changes are made, such that the function can determine the components just from the adjacency matrix, instaed of creating the corresponding graph. The output of this function is a vector of labels, where the i-th entry is the label of the component of the i-th vertex. Second output is a list of vectors, where each vector consists of the vertices of a corresponding component of the graph.

Arguments:

  • adj_mat::AbstractArray{<:Number}: Adjacency matrix
ArcheoGra.ConNetw.connect_components! — Function
connect_components!(adjacency_matrix_daten::AbstractArray{<:Number}, labels::AbstractVector{Int}, component_list::Vector{Any}, dist_matrix::AbstractArray{<:Number})

Function to connect all components from a graph. Function uses only the adjacency matrix as a graph description. The component distinction comes form components(adj_mat::AbstractArray{<:Number}). Components are connect, such that a edge is drawn between vertices of two different components with the shortest distance between them. Distances are taken from distance calculations in distance_allocation(data::AbstractArray{ArchDataEntry}).

Arguements:

  • adjacency_matrix_daten::AbstractArray{<:Number}: Adjacency matrix of graph
  • labels::AbstractVector{Int}: Vector whose i-th entry is the component label of the i-th vertex.
  • component_list::Vector{Any}: List of vectors, where each vector contains the vertices that are contained in the corresponding component.
  • dist_matrix::AbstractArray{<:Number}: Matrix with distances between vertices
