Feature Extraction and Graph Comparison

To analyse the stochastically generated networks robustly, multiple metrics and feature extraction routines are provided. These tools allow for rigorous comparison between different network iterations or distinct time periods. The feature comparison approach is based on The NetSimile approach from Berlingerio, M et. al., NetSimile: A Scalable Approach to Size-Independent Network Similarity, 2012.

Network Feature Extraction

ArcheoGra.ConNetw.feature_extraction — Function
feature_extraction(Ad_weighted::SparseMatrixCSC, edge_comparison::Bool)

Determines the degrees, two-hop degrees, and (optionally) edge lengths of a given weighted graph. The weights must correspond to the edge lengths of the graph.

Arguments

  • Ad_weighted::SparseMatrixCSC: Weighted adjacency matrix of the graph.
  • edge_comparison::Bool: If true, non-zero edge values are also extracted.

Output

  • Tuple{Vector{Int}, Vector{Float64}, Vector{Float64}}: Contains the degree vector, two-hop degree vector, and edge lengths (empty if edge_comparison is false).
ArcheoGra.ConNetw.feature_aggregation — Function
feature_aggregation(feature_vector::Vector{Float64})

Aggregates a feature vector into four statistical categories: mean, median, coefficient of variation, and skewness. This summarizes vectors of different lengths into easily comparable metrics.

Arguments

  • feature_vector::Vector{Float64}: The raw vector of features to aggregate.

Output

  • Vector{Float64}: A 4-element vector containing the aggregated statistics.
ArcheoGra.ConNetw.network_features — Function
network_features(Ad::SparseMatrixCSC, max_distance::Number)

Extracts and aggregates all primary network features from the given adjacency matrix.

Arguments

  • Ad::SparseMatrixCSC: The weighted adjacency matrix.
  • max_distance::Number: Maximum geographic distance used for normalization.

Output

  • Tuple{Matrix{Float64}, Float64, Float64}: Aggregated feature matrix (8x4), normalized diameter, and graph density.

extract_degree_distribution(Ad::SparseMatrixCSC)

Extracts the standard degree and the two-hop degree distribution for all vertices in the graph.

Arguments

  • Ad::SparseMatrixCSC: The adjacency matrix of the graph.

Output

  • Tuple{Vector{Int}, Vector{Float64}}: A tuple containing the degree vector and the two-hop degree vector.
ArcheoGra.ConNetw.extract_clustering_coefficient — Function
extract_clustering_coefficient(Ad::SparseMatrixCSC)

Calculates the local clustering coefficient and the two-hop clustering coefficient for each vertex.

Arguments

  • Ad::SparseMatrixCSC: The adjacency matrix of the graph.

Output

  • Tuple{Vector{Float64}, Vector{Float64}}: A tuple containing the clustering coefficients and two-hop clustering coefficients.
ArcheoGra.ConNetw.extract_egonet_features — Function
extract_egonet_features(Ad::SparseMatrixCSC)

Extracts features related to the ego-network of each vertex, specifically the number of outgoing edges and the number of unique neighbors adjacent to the ego-network.

Arguments

  • Ad::SparseMatrixCSC: The adjacency matrix of the graph.

Output

  • Tuple{Vector{Int}, Vector{Int}}: Outgoing edges from the ego-network and the number of unique neighbors.
ArcheoGra.ConNetw.extract_path_features — Function
extract_path_features(Ad::SparseMatrixCSC, max_distance::Number)

Calculates the betweenness centrality, closeness centrality, and normalized diameter of the graph using an optimized Dijkstra's algorithm with a binary min-heap.

Arguments

  • Ad::SparseMatrixCSC: The weighted adjacency matrix.
  • max_distance::Number: The maximum possible distance for normalization.

Output

  • Tuple{Vector{Float64}, Vector{Float64}, Float64}: Betweenness centrality, closeness centrality, and normalized diameter.

extract_density(Ad::SparseMatrixCSC)

Arguments

  • Ad::SparseMatrixCSC: The adjacency matrix.

Output

  • Float64: The computed graph density.

Distance and Statistical Comparison

ArcheoGra.ConNetw.matrix_spectral_distance — Function
matrix_spectral_distance(matrix1::AbstractMatrix, matrix2::AbstractMatrix, which::Symbol; k_first::Int = 0)

Calculates the spectral distance between two graphs using their corresponding matrices and the Euclidean norm.

Arguments

  • matrix1::AbstractMatrix: First matrix to compare.
  • matrix2::AbstractMatrix: Second matrix to compare.
  • which::Symbol: Specification for the eigenvalues to calculate (e.g., :SM for smallest magnitude).

Keywords

  • k_first::Int: Number of eigenvalues to compute. If 0, all but one are computed.

Output

  • Float64: The computed spectral distance.
ArcheoGra.ConNetw.effective_resistance — Function
effective_resistance(w_lap_mat::SparseMatrixCSC; klargest::Union{Int, Nothing} = nothing)

Determines the effective resistance of an underlying weighted graph using the eigenvalues of its weighted Laplacian matrix. Effective resistance serves as a measure of connectedness.

In order to achieve this, the weighted adjacency matrix uses the inverse edge lengths as its (nonzero) entries. Shorter or additional edges are favorable, while longer or missing edges are penalized.

Arguments

  • w_lap_mat::SparseMatrixCSC: Weighted Laplacian matrix of the graph.

Keywords

  • klargest::Union{Int, Nothing}: Optional number of largest eigenvalues to include. If the smallest eigenvalues are negligible, setting this can accelerate the calculation.

Output

  • Float64: The computed effective resistance.
ArcheoGra.ConNetw.canberra_distance — Function
canberra_distance(d1::AbstractVector, d2::AbstractVector)

Calculates the Canberra distance between two vectors. This method scales with the absolute value of the entries, making it highly sensitive to changes near zero.

Arguments

  • d1::AbstractVector: First feature vector.
  • d2::AbstractVector: Second feature vector.

Output

  • Float64: The Canberra distance.
ArcheoGra.ConNetw.SRGG — Function
SRGG(n::Int, beta::Real)

Creates a Soft Random Geometric Graph (SRGG) with n vertices. Vertices are uniformly distributed in [0,1]^2 and connected using a Rayleigh connection function with parameter beta. The function ensures the final graph is fully connected.

Arguments

  • n::Int: Number of vertices.
  • beta::Real: Parameter for the connection probability.

Output

  • SparseMatrixCSC: The weighted adjacency matrix of the resulting graph.
ArcheoGra.ConNetw.mahalanobis_distance — Function
mahalanobis_distance(x::AbstractVector, μ::AbstractVector, cov_mat::AbstractArray)

Wrapper function to calculate the Mahalanobis distance robustly.

ArcheoGra.ConNetw.mahalanobis_pinv — Function
mahalanobis_pinv(x::AbstractVector, μ::AbstractVector, Σ::AbstractMatrix; rtol::Float64=1e-10)

Calculates the squared Mahalanobis distance using the pseudo-inverse via eigendecomposition, ensuring numerical stability.

Arguments

  • x::AbstractVector: The target vector.
  • μ::AbstractVector: The mean vector.
  • Σ::AbstractMatrix: The covariance matrix.

Keywords

  • rtol::Float64: Relative tolerance to filter out small eigenvalues.

Output

  • Float64: The squared Mahalanobis distance.
ArcheoGra.ConNetw.standardized_distance_squared — Function
standardized_distance_squared(x::AbstractVector, μ::AbstractVector, σ::AbstractVector)

Calculates the squared standardized distance (Z-score squared) between vectors.

Calculates the empirical p-quantile of a sorted vector with linear interpolation.

ArcheoGra.ConNetw.empirical_cdf_interpolated — Function
empirical_cdf_interpolated(sorted::AbstractVector{<:Real}, x::Real)

Evaluates the empirical cumulative distribution function (CDF) with linear interpolation.

ArcheoGra.ConNetw.is_average — Function
is_average(Ad_weighted::SparseMatrixCSC, max_distance::Number, connection_method::String, time_period::String; incl_sources::Bool=false, comparison::Bool=false, p::Real=0.99, output_dir::String=pwd())

Checks if a given network is statistically typical relative to pre-computed network samples by evaluating its Mahalanobis distance.

Arguments

  • Ad_weighted::SparseMatrixCSC: Target network to analyze.
  • max_distance::Number: Normalization baseline for spatial metrics.
  • connection_method::String: Identifier for the directory storing model weights.
  • time_period::String: Historical epoch.

Keywords

  • incl_sources::Bool: References the model utilizing physical source data.
  • comparison::Bool: Toggles evaluation against the comparative baseline.
  • p::Real: Acceptance threshold mapped against empirical CDF. Defaults to 0.99.
  • output_dir::String: Reference to the base output location where statistics reside.

Output

  • Tuple{Bool, Float64, Float64, Float64}: Indicator boolean, calculated probability, raw Mahalanobis distance, and the threshold limit.
ArcheoGra.ConNetw.graph_sensitivity — Function
graph_sensitivity(toml_file::String; num_graphs::Int = 1000, double_distance::Bool = false, output_dir::String = pwd(), overwrite::Bool = false)

Simulates network variations to ascertain robustness of physical connections over multiple statistical passes. Statistics can be created via multiple threads to accelerate the process. Uses all threads available; however the number of threads needs to be preset via the JULIA_NUM_THREADS environment variable by the user.

Arguments

  • toml_file::String: Base setup parameters.

Keywords

  • num_graphs::Int: Number of simulated cycles.
  • double_distance::Bool: Connection probability modifier.
  • output_dir::String: Root path for visual rendering objects.
  • overwrite::Bool: Grants IO operation overwrites.

Output

  • Tuple: Returns aggregated sparse matrices detailing interaction frequencies across epochs.
ArcheoGra.ConNetw.create_graph_statistic_Haversine — Function
create_graph_statistic_Haversine(toml_file::String; num_graphs::Int = 1000, double_distance::Bool = false, output_dir::String = pwd(), overwrite::Bool = false)

Generates statistical features over a large collection of randomized graphs to establish a baseline for the given parameters. Calculates covariance matrices and Mahalanobis distances to allow testing against standard random network expectations. Statistics can be created via multiple threads to accelerate the process. Uses all threads available; however the number of threads needs to be preset via the JULIA_NUM_THREADS environment variable by the user.

Arguments

  • toml_file::String: Path to the configuration TOML.

Keywords

  • num_graphs::Int: Number of simulated graphs to generate for the distribution. Defaults to 1000.
  • double_distance::Bool: Controls the distance penalty calculation. Defaults to false.
  • output_dir::String: Target export folder. Defaults to the active user working location.
  • overwrite::Bool: Permits file deletion if directories exist. Defaults to false.

Output

  • Nothing: Persists statistics, covariances, and distances as text files to the local file system.

High-Level Comparison Pipelines

ArcheoGra.ConNetw.produce_results — Function
produce_results(graph_adj_mat::SparseMatrixCSC; output_dir::String = pwd(), overwrite::Bool = false)

Applies functions for graph comparison: spectral plots, spectral distances, cluster analysis, feature comparison, and effective resistance. The provided graph is compared against standard random models (SRGG, Barabási-Albert, and Watts-Strogatz).

Arguments

  • graph_adj_mat::SparseMatrixCSC: Weighted adjacency matrix of the graph to be analyzed.

Keywords

  • output_dir::String: Directory to save the spectral plot.
  • overwrite::Bool: If false (default), prevents overwriting existing directories.
ArcheoGra.ConNetw.compare_all_is_connected — Function
compare_all_is_connected(start_node::Int, end_node::Int, distance_matrix::AbstractArray{Float64}, material_weight_matrices::Dict, relevant_sites::Vector{ArchDataEntry})

Evaluates connections between sites based on spatial distance and incrementally added material data. Instead of a binary no-material/all-material comparison, it saves each incremental step of additional materials.

Arguments

  • start_node::Int: Index of the primary site.
  • end_node::Int: Index of the secondary site.
  • distance_matrix::AbstractArray{Float64}: Matrix containing spatial distances.
  • material_weight_matrices::Dict: Dictionary of material matrices and distribution ranges.
  • relevant_sites::Vector{ArchDataEntry}: List of valid archaeological sites.

Output

  • Vector{Bool}: A boolean vector representing connectivity at each stage. The first entry is the default connection; the second is the group-adjusted connection; subsequent entries represent added materials.

compare_all_connect_nodes(data::Arch_DataSet, MaterialData::MaterialDataList; prepared::Union{Dict{String,PreparedTimePeriod},Nothing} = nothing, output_dir::String = pwd(), overwrite::Bool = false)

Generates all sub-stage graphs using increasing amounts of materials to trace network evolution.

Arguments

Keywords

  • overwrite::Bool: Grants file overwrite permissions. Defaults to false.

Output

  • Vector{Any}: A collection detailing adjacency matrices, time periods, and site vectors.
