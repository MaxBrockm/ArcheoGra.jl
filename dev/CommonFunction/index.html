Shared funtions across all modules

These core functions are utilized globally across both the ConNetw and LCPA submodules to ensure consistent spatial calculations and reproducible stochastic processes.

ArcheoGra.earth_radius — Constant
earth_radius::Float64

The radius of the Earth in kilometers, primarily calibrated for Central Europe.

This constant serves as the baseline for spatial distance calculations, ensuring correct adjustments for the Earth's curvature when computing direct connections (e.g., Haversine distance).

ArcheoGra.set_seed — Function
set_seed(seed::Int)

Set the global random seed for the reproducibility of stochastic network generation.

Arguments

  • seed::Int: The integer seed value.

Output

  • Nothing
ArcheoGra.distance — Method
distance(u::AbstractArray{Float64},v::AbstractArray{Float64})

Function to determine Haversine distance between two pairs of Coordinates
